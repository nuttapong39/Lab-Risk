# Lab-Risk — Mockup ระบบรายงานความเสี่ยง

Mockup หน้าเว็บระบบรายงานความเสี่ยงออนไลน์ ของโรงพยาบาลพะเยา กลุ่มงานเทคนิคการแพทย์
ออกแบบจากแบบฟอร์มกระดาษ **F-LAB-025 แบบบันทึกความเสี่ยง** ใช้สำหรับให้หัวหน้างานรายงานความเสี่ยงดูก่อนพัฒนาจริง

## หน้าในระบบ

| ไฟล์ | หน้า | ผู้ใช้ |
|---|---|---|
| `index.html` | แบบบันทึกความเสี่ยง (ส่วนที่ 1–5, เลือกระดับ Clinic A–I / Non clinic) | ผู้รายงาน/ผู้ดำเนินการ |
| `list.html` | รายการความเสี่ยง สรุปสถานะ และสัดส่วนตามระดับ | หัวหน้างาน |
| `review.html` | ทบทวนรายงาน และลงนามรับทราบ | ผู้จัดการคุณภาพ |

## เปิดดู

- เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร
- หรือเปิด GitHub Pages: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**

## ข้อควรทราบ

- เป็น **Mockup** เท่านั้น ยังไม่มี backend ปุ่ม "ส่งรายงาน" และ "ลงนามรับทราบ" ไม่ได้บันทึกข้อมูลจริง
- รายการรายงาน ตัวเลข และเหตุการณ์ในหน้า `list.html` / `review.html` เป็น**ข้อมูลตัวอย่าง**
- GitHub Pages เปิดเป็นสาธารณะ ห้ามใส่ข้อมูลผู้ป่วยหรือข้อมูลจริง ระบบที่ใช้งานจริงควรติดตั้งบนเซิร์ฟเวอร์ภายในโรงพยาบาลตามแนวทาง PDPA
